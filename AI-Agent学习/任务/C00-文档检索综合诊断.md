## 需求

写一个小工具，从UTF-8的 `documents.json` 读取文档记录，按关键词检索标题或正文，并返回/显示匹配文档的 `id` 和 `title`。关键词忽略大小写、去掉首尾空格；全空关键词给出明确提示。匹配结果保持输入顺序，默认最多3条，没有匹配则返回空列表。

将读取与检索的职责划分清楚，可以只有一个Python文件，不要求类、CLI参数、框架或指定函数名。可以用函数参数或脚本中的配置指定关键词和结果上限。输入路径固定即可。

文件不存在、JSON损坏、最外层不是列表，或某条记录缺少所需字段/字段类型错误时，给出能区分原因的提示，不伪装成“没有匹配”。本题中 `id` 为字符串，`title`、`content` 为非空字符串；ID唯一是数据前提，不要求去重。结果上限由调用方提供正整数，本题不要求校验所有参数类型。

```json
[
  {"id": "a", "title": "SQL 入门", "content": "使用 SELECT 查询表中的数据。"},
  {"id": "b", "title": "接口开发", "content": "FastAPI 可以提供 HTTP 接口。"},
  {"id": "c", "title": "查询诊断", "content": "使用 SQL 的 EXPLAIN 检查查询计划。"},
  {"id": "d", "title": "知识检索", "content": "先检索相关文档，再组织上下文。"}
]
```

例如关键词 `" sql "` 应得到 `a / SQL 入门` 和 `c / 查询诊断`；`"HTTP"` 得到 `b / 接口开发`；`"不存在的词"` 和有效空输入列表均得到空列表。
