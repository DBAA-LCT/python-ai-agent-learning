# Day 1 — Python 基线任务

## 今日唯一目标

独立完成一个包含“输入、类型转换、条件判断、输出”的小程序，用于评估当前真实起点。

## 任务

编写一个 Python 程序：

1. 让用户输入一个 0～100 的整数分数。
2. 如果分数大于或等于 60，输出 `及格`。
3. 如果分数小于 60，输出 `不及格`。

## 开始写代码前

先用自己的话回答三个问题：

1. 程序的输入是什么？
2. 程序需要判断什么条件？
3. 程序的输出有哪两种可能？

## 规则

- 先独立思考并编写，不搜索完整答案，不让 AI 代写。
- 暂时不要求处理输入字母、负数或超过 100 的情况。
- 可以运行多次检查结果。
- 如果卡住，请说明属于哪一种：
  - A：完全不知道怎么开始
  - B：知道思路但不会写语法
  - C：写了代码但报错
  - D：能运行但解释不清楚

## 自测数据

至少测试：`59`、`60`、`85`。

## 提交内容

- 三个问题的文字答案
- 你独立编写的 `.py` 文件
- 三组自测结果
- 你最不确定的地方（如果有）

> 本任务文件不包含代码答案。
